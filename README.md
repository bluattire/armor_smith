# Armor Smith

_A retexture for the "3d Armor" to add a more fantasy feel_

 ~ A retexture for the "3d Armor" to add a more fantastical and detailed finish to the boxy default textures.

I recommend only downloading this if you're on v5.18+ which would allow you to use this with other texture packs.
